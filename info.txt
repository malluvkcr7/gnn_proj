1. Ablation Studies
● Systematically disable specific model components to quantify their
contribution.
● Verify if sophisticated mechanisms (graph structure or deep layers)
are actually necessary.
● Isolate sources of overfitting or performance gains.
Examples
● Replace the adjacency matrix with an Identity matrix to test if the
model outperforms a standard MLP.
● Replace node features with constant vectors to test if the model
can learn purely from graph topology.
● Compare performance across 2, 4, and 8 layers to identify
"oversmoothing" issues.

5 / 10

2. Visualisation
● Project high-dimensional node representations into 2D space.
● Qualitatively assess how well the model separates different
classes.
● Visually identify distinct clusters or confused boundaries.
Examples
● Plot 2D embeddings colored by ground-truth class to demonstrate
clear cluster separation.
● Use distinct marker shapes for misclassified nodes to see if they
cluster at decision boundaries.

3. Efﬁciency Metrics
● Evaluate the computational ‘cost’ of achieving model accuracy.
● Compare resource consumption across different GNN
architectures.
Examples
● Specific comparison of average training time per epoch and total
inference latency.
● Plot accuracy against the total count of trainable parameters for
each model.
● Log and compare the peak GPU VRAM usage required for each
architecture.

7 / 10

4. Robustness Analysis
● Test model stability against imperfect or noisy data.
● Measure how drastically performance degrades under noise.
Examples
● Plot accuracy degradation curves when randomly removing 10% to
50% of graph edges.
● Add Gaussian noise to node features to simulate sensor errors and
re-evaluate accuracy.
● Compare model performance when training on severely reduced
datasets (e.g., only 5% of labels).

8 / 10

5. Error Analysis by Graph Topology
● Correlate prediction errors with specific structural properties of the
nodes.
● Determine if the model is biased toward specific graph positions
(e.g., hubs).
Examples
● Group test accuracy by node degree (Low vs. High) to see if hubs
are classified more accurately.
● Specific analysis of performance on nodes connected to different
classes vs. same-class neighbors.
● Compare accuracy on the giant connected component versus
isolated outlying subgraphs.

9 / 10

6. Model Explainability
● Uncover why the model made specific predictions.
● Identify which neighbours or features influenced the decision the
most.
● Validate that the model is learning meaningful structural motifs.
Examples
● Visualize GAT attention scores as edge thickness to show which
neighbors were prioritized.
● Use GNNExplainer to highlight the specific sub-graph responsible
for a node's classification.
● Measure the drop in confidence when specific node features are
masked or randomized.
