Complementary Nature of Data

Q: How do node features complement the graph structure?
1 Enriching Message Passing:
Structure defines where information flows (the neighborhood).
Features define what information flows (the semantic payload).
2

Multi-hop Reasoning:
A GNN aggregates neighbor features to generate an embedding.
Example: If a user is connected to many ”Horror” movies (feature), the user node learns a
”Horror-fan” representation (structure + feature), even if the user has no explicit ”Horror”
tag.

Proposed Methodology

We will perform an Empirical Comparison on Link Prediction using:
1. GCN (Graph Convolutional Network) Baseline approach.
2. GraphSAGE (Sample and Aggregate) Good for large datasets where full-batch training is
expensive.
3. GAT (Graph Attention Network) Uses attention mechanisms to weigh neighbors differently.
Crucial for recommendation.
